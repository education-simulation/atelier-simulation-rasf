    👉 Clique sur ce lien pour préparer ton IA : https://atelier.rasf.fr/preparer.html
    puis attends la réponse du prof.
  3. Ensuite, lis en entier le fichier AGENTS.md du dépôt GitHub education-simulation/atelier-simulation-rasf (version brute : https://raw.githubusercontent.com/education-simulation/atelier-simulation-rasf/main/AGENTS.md) et suis-le à la lettre pour guider le prof.
