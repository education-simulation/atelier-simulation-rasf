Quelle IA utilises-tu ?

🚀 Antigravity

Antigravity demande quelques réglages (fermer des fenêtres, le modèle, le mode « Auto »), montrés pas à pas, en animation.

💬 ChatGPT

  1. Rien à régler : ChatGPT lira les consignes sur Internet. Ta simulation sera un fichier sur ton ordinateur, ouvert dans ton navigateur ; à chaque modification, ChatGPT te donne le nouveau fichier à télécharger.
  2. Si ChatGPT dit qu'il ne peut pas lire une page web : sous la zone de message, active « Rechercher » (le globe 🌐), puis réécris « continue ».

✍️ Reviens dans la conversation et écris continue, puis Entrée.

✳️ Claude

  1. Rien à régler : Claude lira les consignes sur Internet. Ta simulation sera un fichier sur ton ordinateur, ouvert dans ton navigateur ; à chaque modification, Claude te donne le nouveau fichier à télécharger.
  2. Si Claude dit qu'il ne peut pas lire une page web : dans le menu des outils, sous la zone de message, active la recherche web, puis réécris « continue ».

✍️ Reviens dans la conversation et écris continue, puis Entrée.

🐱 Le Chat (Mistral)

  1. Sous la zone de message, dans les outils, active « Recherche web » et « Interpréteur de code ».
  2. Ta simulation sera un fichier sur ton ordinateur, ouvert dans ton navigateur ; Le Chat te donne chaque nouvelle version à télécharger.

✍️ Reviens dans la conversation et écris continue, puis Entrée.

✍️ Reviens dans la conversation et écris continue, puis Entrée.

🤖 Une autre IA

  1. Ton IA doit pouvoir lire une page web (recherche web activée) et recevoir un fichier que tu glisses dans la conversation.
  2. Elle te rendra chaque version de ta simulation en fichier .html (ou en code à enregistrer), à ouvrir d'un double-clic.

✍️ Reviens dans la conversation et écris continue, puis Entrée.

Ta simulation sera une seule page HTML : rien à installer.
