Je crée une simulation sur une page html avec l'IA

  1. Ouvre Antigravity (connecté à ton compte Google d'établissement), puis clique sur « + New Conversation », en haut à gauche.
  2. En bas, à droite de la zone de message, clique sur « Default », puis choisis « Auto ». Ainsi, l'IA travaille sans te demander la permission à chaque commande.

    Request ReviewEvery command requires approval.

    DefaultAsk before sensitive operations.

    Auto 👈Automatically decide if commands run.

    TurboRun all commands without restrictions.

    Ask anything, @ to mention, / for actions
    +Gemini 3.8 Flash🔒 Default ⌃🎤⬆

Copie cette phrase, colle-la dans la zone de message, puis appuie sur Entrée : Sans rien lancer, écris seulement « 👉 Clique sur ce lien pour paramétrer Antigravity : » suivi du lien de la page auto.html du site GitHub Pages education-simulation/atelier-simulation-rasf, rien d'autre, puis attends ma réponse.
