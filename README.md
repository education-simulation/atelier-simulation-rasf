# Atelier simulation RASF

> 🤖 **Agent d'Antigravity : tes consignes sont dans [`AGENTS.md`](AGENTS.md).** Lis-le en entier et suis-le à la lettre ; ignore la suite de ce README, qui s'adresse aux humains.

Un atelier pour apprendre à créer une **page HTML de simulation** en parlant à l'agent d'**Antigravity** (l'application gratuite de Google, avec ton compte Google d'établissement). **Rien à installer** : une simulation est un seul fichier `.html`, qui s'ouvre d'un double-clic dans le navigateur.

Les exemples : **1. Métamérisme** (les exemples 2 et 3 arrivent bientôt).

### Pour commencer

👉 **Tout est expliqué, avec une image, sur cette page : https://education-simulation.github.io/atelier-simulation-rasf/demarrer.html** (c'est le lien à envoyer aux profs).

1. Installe **Antigravity** et connecte-toi avec ton compte d'établissement.
2. Ouvre une nouvelle conversation. En bas, à droite de la zone de message (à gauche du micro 🎤), clique sur **« Default »** et choisis **« Auto »** : l'IA pourra travailler sans te demander la permission à chaque commande.
3. Colle cette phrase :

   ```text
   Sans rien lancer, donne-moi d'abord ce lien : https://education-simulation.github.io/atelier-simulation-rasf/auto.html et attends ma réponse. Ensuite, lis le fichier AGENTS.md du dépôt GitHub education-simulation/atelier-simulation-rasf et suis-le pour me guider.
   ```

4. Quand une petite fenêtre « Allow… ? » s'affiche, clique sur **« Yes, and always allow »** (le 3e choix) : c'est sans danger.

### Les fois suivantes

Ouvre Antigravity, ouvre une nouvelle conversation et écris : **« Reprends mon atelier simulation : lis d'abord le fichier AGENTS.md du dépôt GitHub education-simulation/atelier-simulation-rasf »**.
