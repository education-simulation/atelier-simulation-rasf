# Atelier simulation RASF

> 🤖 **Agent d'Antigravity : tes consignes sont dans [`AGENTS.md`](AGENTS.md).** Lis-le en entier et suis-le à la lettre ; ignore la suite de ce README, qui s'adresse aux humains.

Un atelier pour apprendre à créer une **page HTML de simulation** en parlant à l'agent d'**Antigravity** (l'application gratuite de Google, avec ton compte Google d'établissement). **Rien à installer** : une simulation est un seul fichier `.html`, qui s'ouvre d'un double-clic dans le navigateur.

Les exemples : **1. Métamérisme** (les exemples 2 et 3 arrivent bientôt).

### Pour commencer

1. Installe **Antigravity** et connecte-toi avec ton compte d'établissement.
2. Ouvre une nouvelle conversation et colle cette phrase :

   ```text
   Lis le fichier AGENTS.md du dépôt GitHub education-simulation/atelier-simulation-rasf (https://raw.githubusercontent.com/education-simulation/atelier-simulation-rasf/main/AGENTS.md), puis suis-le pour me guider.
   ```

3. Quand une petite fenêtre « Allow… ? » s'affiche, clique sur **« Yes, and always allow »** (le 3e choix) : c'est sans danger.

### Les fois suivantes

Ouvre Antigravity, ouvre une nouvelle conversation et écris : **« Reprends mon atelier simulation : lis d'abord https://raw.githubusercontent.com/education-simulation/atelier-simulation-rasf/main/AGENTS.md »**.

---

Modèle proposé par le RASF. L'ancienne version (site complet avec Node.js et Vercel) est gardée dans [atelier-simulation-rasf-plus](https://github.com/education-simulation/atelier-simulation-rasf-plus).
